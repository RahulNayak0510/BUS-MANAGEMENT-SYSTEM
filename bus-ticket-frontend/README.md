# Bus Ticket Booking Frontend

Angular client for the parent Bus Ticket Booking System repository. For database and backend setup, see the [repository README](../README.md).

Run `npm ci` to install dependencies and `npm start` to serve the app at `http://localhost:4200`. The frontend expects the Spring Boot API at `http://localhost:8080`.

Use `npm run build` for a production build and `npm test` to run the configured unit test suite.
